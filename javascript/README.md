# Room booking component of Library Tools

JavaScript neutral room/time contracts and read-only LibCal discovery/availability. Python also supports booking submission and optional evidence helpers. Callers supply configuration, authorization and transport.

Build a local package with `npm pack --ignore-scripts`. The public
[developer guide](https://github.com/Mathist-Consulting-LLC/library-room-booking-public/blob/main/docs/README.md)
links installation, API contracts, synthetic examples and recovery responsibilities.
